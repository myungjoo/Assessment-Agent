# T-0939 — realdata-e2e dual-leg run report cross-publish title stability single-source convergence non-gated smoke

## Why

PLAN.md 109행 (🟢 실 평가 e2e, P5) step④ (daily-test dual-leg run 결과 rolling-issue 멱등 박제) chain 의 **같은 run 을 여러 밤 연속 publish 할 때, 사람이 이슈 목록에서 읽는 rolling-issue 의 제목(`descriptor.title` = `--title` argv 값)이 1차 create publish 와 그 이후 모든 update publish 에서 어긋나지 않고 안정하며, 나아가 그 제목이 매 publish 마다 단일 source(commandArgs)로부터 재-정규화(re-emit)되어 search-hit 의 title 필드 종속이 아님(issueNumber 처럼 threaded 되지 않음)** — 이 아직 어떤 smoke 에도 chain 그물로 묶이지 않았다.

REQ-009 멱등("동일 run 의 기존 이슈를 찾아 갱신, 중복 생성 안 함")의 cross-publish 안정성은 **여러 매체(medium)** 위에 얹혀 있고, 그 중 사람-향(向) 축은 지금까지 두 개가 봉합됐다:

- **url 축 — 사람 링크(permalink T-0937 이 봉합)** — 사람이 브라우저로 여는 `outcome.url` 이 1차 create 와 이후 모든 update 에서 byte-identical 하게 같은 `.../issues/M` 을 가리킨다. permalink 는 이 **사람-링크 안정성** 을 자산화한다.
- **title 축 — 사람 제목(본 task 가 봉합)** — 사람은 링크를 열기 전에 **이슈 목록에서 제목을 먼저 스캔**한다. rolling-issue 멱등이 성립하려면 1차 밤에 create 로 박은 제목이 2차·3차 밤의 update 후에도 **같은 제목** 이어야 한다 — 그래야 사람이 이슈 목록에서 같은 run 의 rolling-issue 를 제목으로 식별하고, 갱신마다 제목이 조용히 흔들리지 않는다. `descriptor.title` 은 `ISSUE_TITLE_PREFIX + " " + (dateToken@gitSha)` 로 **run 식별(runToken)에서 파생** 돼 같은 run 이면 leg outcome/timestamp 와 무관하게 같은 제목이다(marker 와 동형 단일 source, 단 다른 field·다른 prefix).

그리고 이 title 안정성에는 marker·url 에 없는 **추가 load-bearing 성질** 이 있다: **title 은 search-hit 에서 threaded 되지 않는다.** issueNumber(republish T-0922)는 1차 create-output 의 M 이 2차 search-hit 로 다시 관통해 update argv[2] 로 threaded 되지만, **title 은 매 publish 마다 commandArgs.updateArgs.title(=descriptor.title, 단일 source)로부터 재-발행(re-emit)** 된다. 즉 만약 사람이 GitHub 에서 rolling-issue 제목을 손으로 다른 값으로 바꿔도(search-hit 의 title 필드가 오염돼도), 다음 밤 update publish 는 그 오염된 hit.title 을 이어받지 않고 **descriptor.title 로 다시 정규화** 한다 — 제목이 단일 source 로 self-heal 된다. 이 "title 은 threaded 아니라 re-emit" 성질이 cross-publish 제목 무결성의 핵심 근거다(그래서 title 안정성은 hit.title 이 무엇이든 무관하게 성립한다).

그러나 이 **cross-publish title stability single-source(및 hit-오염 재정규화)** 를 어느 smoke 도 검증하지 않는다:

- 형제 T-0930(title cross-branch)은 **한 chain 내부** 에서 create argv `--title`(빈 search 분기)과 update argv `--title`(marker-hit 분기)이 단일 `descriptor.title` 로부터 byte-identical 함만 자산화한다 — **여러 publish 에 걸친**(여러 밤 재조립) 안정성·hit.title 오염 시 재정규화는 대상이 아니다(intra-chain ≠ cross-publish, T-0928/T-0929 vs T-0938 의 그 구분과 동형).
- 형제 permalink(T-0937)는 `outcome.url` 의 cross-publish 안정성(사람-**링크**)만 자산화한다 — url 은 execute-side output-parse 산물, 본 task 의 title 은 pre-exec 명령-args 의 사람-**제목** 이라 다른 축(사람-링크 ≠ 사람-제목).
- 형제 marker(T-0938)는 `searchQuery`(=marker, 검색 anchor)의 cross-publish 안정성 + round-trip 만 자산화한다 — marker 와 title 은 **같은 runToken 을 공유** 하지만 서로 다른 field(prefix 가 다름: ISSUE_MARKER_PREFIX vs ISSUE_TITLE_PREFIX)라 co-sourced 이지만 orthogonal(검색 anchor ≠ 사람 제목).
- 형제 republish(T-0922)는 issueNumber M 이 hit 로 threaded 됨만 자산화한다 — title 이 threaded **아님**(re-emit)은 그 거울상 성질인데 아무도 단언하지 않았다.

본 task 는 그 **cross-publish title stability + hit-오염 재정규화 seam** 을 닫는다 — cross-publish 안정 trilogy 의 사람-제목 짝(그리고 title 이 issueNumber 처럼 threaded 아니라 단일 source re-emit 임을 못 박는 축). chain: 두 leg outcome + run → report → descriptor → commandArgs 를 통과시켜 사람-제목 `descriptor.title`(=`--title` argv 값)을 얻고, (1차) 빈 search(`"[]"`)로 create plan → create argv 의 `--title` 다음 원소, (2·3차) 1차 create body 를 그대로 담은 search-hit → resolve(marker 매칭 → update) → update plan 의 `--title` 다음 원소를 산출한 뒤, 세 publish 의 `--title` 값이 모두 byte-identical(=descriptor.title=createArgs.title=updateArgs.title) AND hit.title 을 오염시켜도 update argv 의 `--title` 이 여전히 descriptor.title(단일 source)로 재정규화됨을 박제한다.

issue-still-relevant 확인(2026-07-12): `ls test/smoke | grep dual-leg | grep -iE "cross-publish|title.*stab|stab.*title"` = 제목 관련 0개(cross-publish marker/url stability 2개는 marker·url 축 — title 미봉합), `ls test/smoke | grep title` = `title-cross-branch`(T-0930, intra-chain) 뿐. `git log origin/main` 동일 영역(dual-leg cross-publish title stability smoke) 박제 commit 0. descriptor 빌더(title=ISSUE_TITLE_PREFIX+runToken)·command-args 빌더(createArgs.title/updateArgs.title=descriptor.title)·종단 컴포저(resolve, T-0902) 배선은 이미 main 에 박제됨 — 본 task 는 그 배선을 **다시 만들지 않고** 여러 publish 의 --title 상호 동일성 + hit-오염 재정규화를 대조하는 **smoke 그물만** 신설.
